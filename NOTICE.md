# Release.Senvas

This repository hosts **Velopack release artifacts only** for Senvas HMI (installer, update packages, update metadata).
Tags `v1.1.x` belong to the previous-generation product SenvasHMI; `v2.x` and later are Senvas.

No source code is distributed from this repository. Source code is maintained privately by Going.

The binaries are provided as-is without warranty. Third-party components are used under their respective licenses
(.NET runtime, WPF-UI, AvalonEdit, AvalonDock, SkiaSharp, FontAwesome, Markdig, CommunityToolkit.Mvvm, GuiLabs.Undo,
ModelContextProtocol, Velopack, and others); their notices are included in the installed application folder where required.

## Install

Download `Senvas-win-Setup.exe` from the [latest release](https://github.com/going-kr/Release.Senvas/releases/latest).
